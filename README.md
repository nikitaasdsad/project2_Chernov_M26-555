\# Primitive DB



Primitive DB - это консольная база данных, написанная на Python. Проект поддерживает создание и удаление таблиц, а также полный набор CRUD-операций (создание, чтение, обновление и удаление записей). Все данные и метаданные сохраняются в JSON-файлах. Программа оснащена обработкой ошибок, кэшированием запросов и запросом подтверждения для опасных операций.



\## Требования



Для работы проекта требуется Python версии 3.12 или выше, а также менеджер пакетов `uv` (или `poetry`).

В проекте используется `uv`, но для удобства настроен `Makefile`.



\## Установка



Для установки всех зависимостей и создания виртуального окружения выполните команду:



```bash

make install

```

\*(или uv sync`).\*



\## Запуск



Чтобы запустить базу данных, выполните:



```bash

make run

```



\*(или uv run database).\*
